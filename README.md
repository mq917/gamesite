# Игра на двоих — битва полов

Сайт для игры вдвоём: без регистрации, подбор соперника противоположного пола
близкого возраста, 10 игр, чат с эмодзи, счётчики онлайн. Вся игровая логика —
на фронтенде (в браузере), сервер только сводит пары и пересылает сообщения.
Никакие данные никуда не сохраняются: ни на диск, ни в базу данных — всё живёт
в оперативной памяти процесса, пока открыта вкладка.

## Структура проекта

```
gamesite/
  server/
    server.js       — весь бэкенд в одном файле (Node.js + ws)
    package.json
  public/
    index.html       — разметка (модалки, лобби, комната игры)
    css/style.css     — вся стилистика, тёмная/светлая тема
    js/app.js          — подключение, лобби, матчмейкинг, чат
    js/games/*.js       — 10 независимых игровых модулей
```

## Как это работает

1. Игрок вводит никнейм, пол и возраст (хранится только в вкладке браузера).
2. Выбирает игру → попадает в очередь ожидания.
3. Сервер ищет в очереди игрока того же game, противоположного пола, с разницей
   в возрасте не больше текущего допуска (±2, увеличивается на 2 каждые 15
   секунд ожидания, до ±20).
4. Обоим показывается карточка друг друга — нужно **обоюдное согласие** («Играть!»),
   иначе (при отказе) сервер запоминает эту пару только в рамках соединения —
   как только вкладка закрывается, все ограничения слетают.
5. После согласия — комната: доска игры + чат. Все ходы и сообщения идут
   через WebSocket, сервер их не понимает и не проверяет, просто пересылает
   второму игроку.
